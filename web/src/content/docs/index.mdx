`zot` is a CLI and AI-agent toolkit for full **read-write** control of your
*local* Zotero library: search, bulk-edit metadata, tag, deduplicate, import by
DOI/ISBN/arXiv, export, and summarize PDFs into notes. Zotero's local API is
read-only, so writes go through a tiny token-protected plugin — no zotero.org
account, no API key, no cloud.

## Why zotero-agent

<CardGrid>
  <Card title="Local-first & private" icon="approve-check">
    Your library never leaves your machine. Reads hit Zotero's local HTTP API;
    writes go through a loopback-only plugin. Nothing is sent to a cloud service.
  </Card>
  <Card title="Full local read-write" icon="pencil">
    Zotero's local API is read-only by design. The bridge plugin is the only
    complete **local** write path — real batch edits, dedup and tag cleanup on
    your own disk.
  </Card>
  <Card title="Agent-ready and scriptable" icon="rocket">
    Works as an MCP server for Claude Desktop, Codex CLI, Gemini CLI and Cursor —
    and as a plain CLI you can pipe, script, and drop in a Makefile.
  </Card>
  <Card title="Honest security" icon="shield">
    A documented three-layer model: required token, browser-origin guard,
    loopback binding, plus an append-only audit log — not an insecure debug bridge.
  </Card>
  <Card title="PDF tables of contents" icon="open-book">
    Zotero's reader shows a PDF's outline but cannot create one. `zot toc` builds
    it — from the book's own contents page where there is one, from typography
    where there isn't — and writes it into the file.
  </Card>
  <Card title="Scanned books, made usable" icon="document">
    A book scanned two pages at a time cannot be searched, cited or read by an
    agent. `zot pdf-prep` finds the fold, splits it into single pages, OCRs it
    and shrinks it — 24.7 MB and unsearchable to 16.4 MB and searchable, without
    the file leaving the item.
  </Card>
</CardGrid>

## Quickstart

```bash
uv tool install "zotero-agent[mcp,toc]"   # the CLI, + MCP server, + the PDF tools
# or, on macOS/Linux:  brew install alex-roc/tap/zotero-agent   (extras included)
# then install the bridge plugin XPI: Tools -> Plugins -> gear -> Install Plugin From File
zot init                               # generate a token, detect your userID
zot ping                               # verify: local API up, bridge answering
```

## How it compares

| | Local write | Needs account / API key | Works offline | Agent-ready (MCP) | Open source |
|---|:---:|:---:|:---:|:---:|:---:|
| **zotero-agent** | ✓ | no | ✓ | ✓ | ✓ |
| zotero-mcp | web only | yes | no | ✓ | ✓ |
| pyzotero | web API | yes | no | library | ✓ |
| Better BibTeX JSON-RPC | almost none | no | ✓ | no | ✓ |
| Beaver | ✓ (cloud backend) | freemium account | no | GUI | no |
